# Smart Parking Client

## Запуск dev-сервера

### Быстрый запуск (автоматический выбор)

Просто выполните:
```bash
./start-dev.sh
```

Скрипт автоматически определит, какой сервер использовать (Vite или Python).

### Вариант 1: Vite (рекомендуется)

1. Установите зависимости:
```bash
npm install
```

2. Запустите dev-сервер:
```bash
npm run dev
```

Сервер будет доступен по адресу: http://localhost:5173

### Вариант 2: Python HTTP Server

Если у вас установлен Python 3:

```bash
python3 -m http.server 8000
```

Сервер будет доступен по адресу: http://localhost:8000

### Вариант 3: Node.js http-server

1. Установите глобально:
```bash
npm install -g http-server
```

2. Запустите:
```bash
http-server -p 8000
```

## Важно

⚠️ **Не открывайте `index.html` напрямую через `file://` протокол!**

History API не работает с `file://` протоколом из соображений безопасности. Всегда используйте HTTP сервер для разработки.
